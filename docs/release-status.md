# 当前成果、注意事项与下一步

更新：2026-10-19，MIT公开版本，独立发布当前脱敏实现。工程验证与真实学校业务验收分别记录。

| --- | --- | --- |

## 本轮确认通过

- **可选凭据恢复**：默认不保存密码，显式cred-save或init --save-cred后使用；统一会话失效时重登并重试一次，成功/partial/失败按最终查询状态描述，独立体测令牌不误触发。超期或认证拒绝提示更新，网络故障不直接当作密码错误。
- **认证文件协调**：会话提交、切号/退出、凭据保存/清除/状态回写共用跨进程文件锁，版本校验在提交区内完成；旧结果不覆盖新凭据，清除后旧回写不恢复密码，CLI autologin也绑定启动版本。同秒会话更新使用不同版本号。六项新增回归先复现旧缺陷再通过。

- **激活失败保旧**：成绩与网页课表的首查、热查、910恢复及关闭记忆路径中，激活 GET 网络/HTTP/登录错误均终止；失败返回旧成功快照的 partial，不能把空 POST 当作“已经核验没有数据”。同会话跨功能码串行，LRU不再移除使用中的会话锁，HTTP500正文含910也不扩大成激活重试。独立37项合成检查通过。
- **附件**：唯一精确名称、真实年级字段与多值/冲突校验、账号/年级/方案身份哈希、ZIP/DOCX检查、独立临时文件、进程内发布串行、失败回滚验证、内容控件保序提取。文件逐个替换并校验回滚，不是跨文件或跨进程事务；未支持内容应查看 text_complete。
- **电表与余座**：月份解析、跨月查询范围、异常结构、失效连接最多重建一次、固定账号上下文、取数完成时间与旧快照标记。余座自动查询默认在发送 Cookie 前拒绝，提供官方人工入口，不预约、不占座、不签到。
- **电表迁移**：核对既有成功记录与配置中双方非空的楼栋、楼层、房间和园区 ID；冲突时在取源前拒绝，不写绑定。实现此前的独立13项检查通过，未把缺少字段当作已证明设备归属。
- **备份 CLI**：拒绝源目标相同；已有目标默认拒绝，明确 --force 才允许覆盖。备份仍含私人数据，不应上传。

原目录与脱敏main公开副本各通过399项回归、零跳过；实际stdio发现47工具，七次调用覆盖五项空配置门禁、真实恢复编排后的合成课表成功以及上游失败，schema、文本/结构和错误标志一致。测试使用合成认证/来源和空data，父子学校HTTP禁用；没有新增真实成绩、设备、学校实际失效恢复或WorkBuddy自然语言全程验收。

## 已实现的提速

- 成绩总表、成绩明细、两种课表及考试的成功非空结果复用60秒，可用 force_refresh 刷新首页；游标续页仍固定原快照。
- 网页课表同一完整本地快照汇总可见课程已知学分，提供缺值/冲突与分段计时；不等于已获学分或毕业资格。
- 教务激活记忆现已默认开启，按会话协调；`ZJGSU_JW_ACTIVATION_MEMO=0` 可关闭。服务端激活生命周期仍未实测，30分钟是本地保守上限。
- 电表按设备复用匿名连接会话，每次仍读取业务页，不缓存余额作为当前值；复用 SSLContext 保持证书与主机名校验，不宣称 urllib 已有连接池。
- SQLite 使用 WAL + synchronous=FULL，选定路径将快照和健康记录合并事务；`ZJGSU_STORE_JOURNAL=DELETE` 可回退日志模式。维护脚本提供 status/checkpoint/backup。

报告中的学校网络计时来自实施方少量样本，本轮没有重测学校 A/B 或 WorkBuddy 从提问到回答的全过程。不把单次样本、合成延迟或本机测试套件耗时当作用户查询速度承诺。通用 CLI、brief 与工具描述精简未交付；已有学分专用 CLI 和缓存库维护 CLI 不等于通用直查入口。

## 按能力保留的限制

47个工具中包含当前仅提供人工入口或需要额外本人配置的能力；注册数不是学校信息覆盖率。余座默认人工导航，电表定位由本人核实，培养方案正文须看文件身份、版本及text_complete，不能自行据此认定毕业资格。

其他持续限制见[限制清单](limitations.md)：综测业务结果、劳动本人非空记录、全部历史与账号适用性仍未全部独立验收；P0进程内锁不宣称跨进程协调，附件不用于自行认定毕业资格。

## 使用和隐私边界

只读取本人有权访问的信息；本人借阅取消，校园卡、畅约及跳转畅约的入口仅简介和人工导航。不报名、签到、预约、支付、提交或审批，不绕过访问限制。

余座的 HTTP Cookie 门禁保留；不要为日常查询打开 `ZJGSU_SEAT_ALLOW_INSECURE_HTTP`。尚未验证可用的 HTTPS 业务入口，不把一次失败观察说成永久不支持 HTTPS。匿名电表可访问不证明设备归属；source=live只说明本次读取，不证明源数据此刻状态。partial/不完整覆盖不能回答成“没有”。

会话为本机明文JSON，缓存/备份也可能含私人信息；忽略规则不等于加密或访问控制。仓库不分发真实data、会话、附件、账单、截图、HAR、抓取或真人计时脚本、私人交接及原始验证日志。作者授权的联系方式保留。学校查询按需发生，无后台轮询、保活或公共代查。
