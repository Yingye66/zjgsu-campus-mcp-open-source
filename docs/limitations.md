# 当前范围与限制

## 可选凭据恢复的边界

默认不保存密码；显式开启后credentials.json为本机明文JSON，Windows ACL未自动收紧。保存时效、失败熔断和跨进程协调不能代替操作系统/备份权限保护。只应在本人可信机器使用，详情与停用步骤见[快速开始](quickstart.md#可选保存凭据并自动恢复)。

历史版本的399项回归及本地stdio使用合成认证/来源；本轮未新增学校实际失效恢复、所有账号适用性或WorkBuddy全程验收。Windows跨进程竞争已测试，POSIX锁实现未在本轮实机验证。文件锁协调仅限同一数据目录中遵守协议的认证代码；手工改文件、旧进程仍运行旧代码或其他业务适配器的进程内锁不包含在此保证中。更新后要重载本MCP，避免新旧代码同时操作同一私人目录。

认证拒绝先在当前进程停止重试，并尝试持久化状态；磁盘不可写时，重启不保证保留该失败标记，应先检查状态或更新凭据。App课表99码仍是有限来源的恢复线索，不是官方错误语义。教务查询需要教务CAS实际可用，只有App登录成功不保证成绩可查；失败会如实返回。

本版本提供 48 个注册工具；原项目与公开副本各通过 `421` 项合成回归。注册数和测试数都不是学校信息覆盖率、全部来源在线可用或全部真人验收。

## 本轮已修复的范围

先前的激活失败误判空、附件模糊代选/账号年级错件/临时文件冲突、常规回滚、内容控件遗漏，以及电表月份/部分结构异常、余座账号上下文等已修复并通过针对检查。余座、电表已有专用 schema 和最小 freshness/失败旧快照契约。

电表旧定位首次迁移已逐字段核对楼栋、楼层、房间及园区 ID：双方已有的非空值冲突时，在读取来源之前拒绝并要求重新解析；一致或缺少对照字段时不误拒绝。本轮独立迁移检查 13/13 通过。这只核对本机既有证据的一致性，不证明未知字段或设备归属。

## 当前已知缺口

- 公众号查询只覆盖本地订阅，记录时间可能为采集时间，最新成功采集时间与完整性未知；分页中途数据变化可能漏项或重复。查询服务只读，上游采集器独立且不受此保证约束，详情见[工具索引](tool-reference.md#get_mp_articles)。

- 余座默认拒绝HTTP发送Cookie，当前仅推荐官方人工入口；HTTPS业务路径尚未成功核实，不能据单次失败断言永久不可用。排障开关不适合日常启用。
- 电表通过匿名访问链路读取，来源设备的刷新规律尚未独立核验；仅限本人明确授权的设备。缺少定位对照证据不等于已证明归属，不枚举其他住户。
- 附件按文件替换和回滚验证，只有进程内串行，未提供跨文件/跨进程事务；恢复失败时unavailable并保留备份。文本提取有明确完整性标志，但不代替学校文件版本与毕业要求核对。
- 两个新服务的schema与状态JSON仍为最小契约，未统一到旧工具全部coverage/pagination语义；字段schema存在不能代替业务完整性证明。
- 激活记忆的服务端生命周期、全部跨工具真实网络行为，以及WorkBuddy端到端耗时未由本轮独立复验；会话锁在进程内，变更多进程部署前需另验。

## 尚未完成的业务对照

综测评分构成/排名映射、本人劳动非空时数与完成记录、体测专用令牌全部账号与历史范围、部分新闻正文/检索详情及分页仍有限定。课表学分只是当前来源可见课程的已知小计，不是全量培养要求或毕业资格。

本人借阅取消；校园卡、畅约和跳转畅约的入口仅人工导航。所有业务写操作不提供。私有认证需要本人合法配置；clone仓库不能直接获得私人数据。会话/缓存/备份仅本机保存，明文文件和.gitignore不提供加密或访问控制。没有后台监控、保活或公共代查部署。
