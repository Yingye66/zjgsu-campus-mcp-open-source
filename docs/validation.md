- 未新增学校全部业务、所有账号、所有历史范围或WorkBuddy自然语言全程验收。
- 余座默认不发送明文Cookie，提供人工入口；不能把注册数当作47条在线数据通道。
- 综测业务映射、本人劳动非空记录及部分详情/分页仍有范围限制，见[限制清单](limitations.md)。
- 私人认证需要使用者自己的合法账号和本机配置，源码和MIT许可不提供学校访问权限。
- 性能计时不包含全部模型与客户端等待，不承诺固定端到端秒数，见[查询提速](performance.md)。

正式测试可在仓库根目录执行：

```powershell
& .\.venv\Scripts\python.exe -B -m unittest discover -s test -t . -v
```

完整测试含本地stdio子进程；跳过子进程不能记成完整通过。原始私人记录和本机发布证据不随仓库分发。
